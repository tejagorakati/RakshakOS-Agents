# RakshakOS-Agent

RakshakOS is a multi-agent AI system designed for intelligent disaster response and resource management.

It collects data from multiple sources such as satellite imagery, weather, disaster alerts, maps, traffic, and ground reports. The system verifies the information, assesses the situation, coordinates available rescue resources, and generates response plans.

The system uses specialized AI agents for:
- Situation & evidence analysis
- Ground verification
- Impact assessment
- Resource management
- Response planning
- Monitoring & re-planning

RakshakOS also provides separate interfaces for rescue teams and officials, with support for SMS-based communication and continuous re-planning when conditions change.
